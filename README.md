## 🚀 Featured Projects

<details open>
<summary><b>💰 MRP Interestly — Financial Math & Precision Interest Calculator</b></summary>
<br/>

High-precision financial calculation web app for interest computation, loan amortization, EMI planning, investment projection, and audit-grade PDF reporting — built solo end-to-end.

| Aspect | Detail |
|---|---|
| **Stack** | React 19, TypeScript, Vite 6, Tailwind CSS v4 |
| **Scale** | 6+ calculation modules: date-ledger, EMI, SIP, amortization, multi-currency |
| **Performance** | Client-side compute, PWA + offline support via Service Worker |
| **Security** | Firestore rules configured, `.env`-based config isolation |
| **Impact** | Live production deployment, MIT licensed, community-starred |
| **Repository** | [milin3287/Intrest-Calculator](https://github.com/milin3287/Intrest-Calculator) |

Supports Simple Interest and Daily Compounding modes, 360/365-day conventions, multi-currency formatting (₹ with Lakh/Crore notation, $, €, £, ¥), and generates audit-grade PDF statements via jsPDF. Includes a step-by-step mathematical solver for deriving principal, rate, time, or future value.

🔗 **Live:** [intrest-calculator-gamma.vercel.app](https://intrest-calculator-gamma.vercel.app)

</details>
